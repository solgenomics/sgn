# Breedbase / SGN

This repository contains the [Breedbase system](https://breedbase.org), including
[Cassavabase](https://cassavabase.org/), [Musabase](https://musabase.org),
[Sweetpotatobase](https://sweetpotatobase.org) and [Yambase](https://yambase.org),
and the [Sol Genomics Network](https://solgenomics.net/) site.

Ready Docker images are available on the
[Breedbase DockerHub page](https://hub.docker.com/r/breedbase/breedbase).
Build scripts are in the
[breedbase_dockerfile repository](https://github.com/solgenomics/breedbase_dockerfile).

To run Breedbase, clone the
[breedbase_site repository](https://github.com/solgenomics/breedbase_site/).
The prerequisites are Git, nginx, Docker and Docker Compose. Follow the
[breedbase_site wiki](https://github.com/solgenomics/breedbase_site/wiki).

For more information, use the [SGN contact form](https://solgenomics.net/contact/form).

Users should refer to the [user manual](https://solgenomics.github.io/sgn/).

Optional interface and user-manual translations are documented in the
[localization guide](docs/i18n/README.md).

Developers should refer to the [developer guide](https://github.com/solgenomics/sgn/wiki).
See the [internationalization chapter](docs/i18n/DEVELOPER.md) for adding and
debugging translated messages.
